# Frankenstein Lab

تطبيق Android عربي قيد التطوير يجمع وحدات مفتوحة المصدر محددة مع وظائف محلية مدمجة فعليًا. هذه النسخة **ليست المنتج الكامل** في وثيقة المواصفات؛ توضح [حالة الدمج](INTEGRATION_STATUS.md) ما يعمل وما لم يُنفّذ.

## الموجود في الشيفرة الآن

واجهة Android أصلية بـKotlin وJetpack Compose تدعم RTL، ومظهرين فاتحًا وداكنًا، وهوية Vector أصلية محلية. المكتبة تحفظ URI الملف المحلي ونوعه والتقدم، وتتيح البحث وإزالة فهرس العنصر دون حذف الملف. يمكن فتح EPUB وCBZ وفيديو محلي من منتقي Android.

قارئ EPUB يستخدم محلل Grimoire المنقول، مع عرض الفصول والصور والنص وتغيير حجم الخط وحفظ الفصل. قارئ CBZ يعرض الصفحات رأسيًا باستمرار أو بالتقليب الأفقي RTL ويحفظ الصفحة، ويربط نموذج صفحات المشهد بـReader Core من Kototoro. الفيديو المحلي يعمل عبر Media3 ExoPlayer ويحفظ موضع التوقف. مدير الملفات الداخلي يستخدم Storage Access Framework ويتيح التصفح وإنشاء مجلد وإعادة تسمية ونسخًا ونقلًا وحذفًا مؤكدًا، من دون إذن تخزين عام. توجد تفضيلات محلية ودليل استخدام عربي واستعادة للإعدادات الحالية.

## ما ليس منفذًا بعد

لا توجد مستودعات أو إضافات قابلة للتثبيت أو محركات توافق Kotori/Mihon/Aniyomi/CloudStream/Grimoire، ولا مصادر بث أو بحث خارجي أو مدير تنزيلات، ولا مشغلات mpv/Kototoro/Zangetsu، ولا مزامنة/تتبع حسابات، أو ذكاء اصطناعي/TTS، أو نسخ احتياطي. لا تُعرض هذه الخدمات على أنها موجودة.

استُبعد Zangetsu وفق توجيهك بأنه Flutter. لم يُخترع مستودع Club Stream لأن رابطه المحدد غير متوفر. المحتوى المحلي فقط هو المدعوم حاليًا.

## بنية المشروع

- `app/` — تطبيق Android وواجهة المستخدم والتخزين ومدير ملفات SAF.
- `modules/manga-reader-core/` — Reader Core المصدر من Kototoro واختباراته.
- `modules/novel-epub/` — محلل EPUB المصدر من Grimoire واختباراته.
- `THIRD_PARTY_NOTICES.md` — إشعارات المصادر والتراخيص المباشرة.
- `SOURCE_AUDIT.md` — سجل تدقيق المستودعات وحدود الاقتباس.
- `INTEGRATION_STATUS.md` — ما دُمج وما لم يُدمج.

## بيئة التطوير

يلزم Android SDK API 37، وJDK 21 كما يطلب مصدر Kototoro/إعداد البناء، وGradle Wrapper المبيّن في `gradle/wrapper/gradle-wrapper.properties` (9.7.0). الحدود المعلنة هي `minSdk 26` و`targetSdk 36`.

عند السماح بحل الاعتماديات وتشغيل البناء، نقطة البدء المقترحة:

```bash
./gradlew :app:assembleDebug
./gradlew :modules:manga-reader-core:jvmTest :modules:novel-epub:jvmTest
```

**لم تُشغّل أوامر Gradle أو تُحل الاعتماديات أو يُبنَ APK أو تُنزّل وسائط/كتب/موارد تطبيقات** احترامًا لطلبك. لذلك لا يُدّعى أن تطبيق Android جرى بناؤه أو اختباره على جهاز؛ راجع `TESTING.md`.

## التراخيص

راجع `THIRD_PARTY_NOTICES.md` و`SOURCE_AUDIT.md`. احتُفظ بترخيص Apache-2.0 وإسنادات وحدتي Kototoro وGrimoire. لم تُنسخ APKs أو كتب أو صور أو فيديوهات أو حمولات مستودعات محتوى. يلزم استكمال جرد الاعتماديات الانتقالية قبل توزيع أي ملف ثنائي.
