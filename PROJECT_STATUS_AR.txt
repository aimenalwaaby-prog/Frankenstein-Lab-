تقرير حالة مشروع Frankenstein Lab
التاريخ: 15 أكتوبر 2026
المستودع: https://github.com/aimenalwaaby-prog/Frankenstein-Lab-
الفرع الجاري العمل عليه: main

ملخص تنفيذي
------------
أُضيفت إلى المستودع قاعدة تطبيق Android عربية مع وحدات مصدرية فعلية من Kototoro وGrimoire، ووظائف محلية للقراءة وتشغيل الفيديو وإدارة الملفات، كما أُضيفت نسخة احتياطية JSON محدودة للبيانات المتاحة حاليًا. المشروع ليس بعد التطبيق الكامل في المواصفات. لم يُشغّل البناء أو الاختبارات، ولم يُبنَ APK، ولم تُنزّل كتب أو فيديوهات أو صور أو موارد تطبيقات، التزامًا بطلبك. لذلك فوجود الشيفرة لا يعني أن ترجمتها أو عملها على جهاز قد تم إثباته.

ما اكتمل في الشيفرة
-------------------
1. المصدر المفتوح والتراخيص
- نُقل Reader Core من Kototoro إلى modules/manga-reader-core، مع اختباراته المصدرية وإشعارات Apache-2.0.
- نُقل محلل EPUB المحدد من Grimoire إلى modules/novel-epub، مع اختبار محلي وملف ترخيص Apache-2.0 محفوظ.
- أضيفت ملفات THIRD_PARTY_NOTICES.md وSOURCE_AUDIT.md وARCHITECTURE.md وINTEGRATION_STATUS.md لتوثيق المصدر والقيود.
- لم تُنسخ APKs أو مكتبات وسائط أو كتب أو صور أو قواعد محتوى.

2. قاعدة تطبيق Android والوظائف المحلية
- تطبيق Kotlin/Jetpack Compose بهوية Frankenstein Lab وواجهة عربية RTL ومظهر فاتح/داكن.
- مكتبة محلية تحفظ URI والنوع والتقدم، مع بحث وإزالة الفهرس دون حذف الملف الأصلي.
- قارئ EPUB محلي يستخدم محلل Grimoire، ويعرض الفصول والنصوص والصور ويتيح تغيير حجم الخط وحفظ الفصل.
- قارئ CBZ محلي يعرض الصفحات بتمرير رأسي أو تقليب RTL، ويحفظ الصفحة ويصغر الصور الكبيرة.
- مشغل Media3 لملف فيديو محلي، يحفظ موضع التوقف ويوقف التشغيل في الخلفية ويحرر جلسة اللاعب عند الخروج.
- مدير ملفات عبر Android Storage Access Framework: تصفح، إنشاء مجلد، إعادة تسمية، نسخ، نقل وحذف مؤكد. لا يطلب صلاحية تخزين عامة. عند تعثر حذف أصل عملية نقل، تبقى النسخة التي أُنشئت في الوجهة بدل حذفها، لتقليل خطر فقد البيانات.
- تفضيلات محلية للمظهر ووضع المانغا وحجم النص، مع استعادة الافتراضيات ودليل استخدام عربي.

3. النسخ الاحتياطي والاستعادة المحدودة
- يمكن للمستخدم اختيار تضمين فهرس المكتبة/التقدم و/أو الإعدادات.
- تنشئ الشيفرة JSON بإصدار صيغة 1 وحد أقصى للحجم والعناصر، وتتحقق من SHA-256 قبل عرض معاينة الاستعادة.
- الاستعادة تدمج العناصر الجديدة فقط، وتتجاهل URI والنوع المكررين ولا تستبدل تقدم المكتبة الحالي. استعادة الإعدادات تستبدل الإعدادات بعد تأكيد المستخدم.
- لا تحتوي النسخة ملفات EPUB أو CBZ أو الفيديو، ولا أذونات Android/SAF، ولا مفاتيح API أو بيانات اعتماد. الملف غير مشفر ويحتوي عناوين العناصر وURIs وتقدمها؛ اختر مكان حفظ خاصًا. عند النقل إلى جهاز آخر قد يلزم إعادة اختيار الملفات.

ما بقي غير مكتمل
-----------------
- لم تُشغّل أي مهمة Gradle؛ لم تُحل الاعتماديات ولم يُترجم تطبيق Android أو تُشغّل اختبارات JVM. لا يوجد تحقق على محاكي/جهاز، ولا APK. فحص هذه المرحلة ساكن فقط.
- محركات المستودعات والإضافات غير مدمجة: لا يوجد توافق تشغيل فعلي لأنظمة Kotori أو Mihon أو Aniyomi أو Nekoyomi أو CloudStream أو Grimoire، ولا مصادر شبكة أو بحث موحد أو بث.
- لا توجد إدارة تنزيلات أو تحديث مصادر/فصول، ولا مزامنة أو سجل قراءة/مشاهدة مستقل أو مفضلات وقوائم. التقدم المحفوظ حاليًا هو موضع واحد لكل عنصر محلي.
- لا توجد وظائف ذكاء اصطناعي أو مزود خدمة أو حفظ مفتاح آمن أو محادثات أو توليد صور أو TTS.
- لا توجد مشغلات Kototoro أو mpv-android أو صورة داخل صورة أو إعدادات صوت/ترجمة/جودة. Zangetsu مستبعد وفق توجيهك لأنه Flutter.
- قارئ المانغا لا يوفر كل قدرات واجهة Kototoro الأصلية مثل التكبير/الإيماءات/المصادر والتنزيلات؛ ما دُمج هو Reader Core المختار مع عرض CBZ محلي.
- النسخة الاحتياطية لا تحفظ المحتوى الفعلي أو الأذونات ولا تشفر الملف. لا توجد آلية تحقق من توفر URI المستعاد قبل إدراجه؛ على المستخدم إعادة اختيار الملف عند فقد الإذن.
- لا توجد اختبارات Instrumented أو اختبارات واجهة/تكامل لمدير الملفات أو المشغل أو النسخ والاستعادة. لم يثبت بعد التوافق مع كل مزودي SAF أو أداء جهاز متوسط.
- جرد الاعتماديات الانتقالية/SBOM وإشعاراتها النهائية مطلوبان قبل توزيع ثنائي.
- رابط مستودع Club Stream المقصود لم يحدد، لذلك لم يُخمن. لم تُدمج شيفرة من المشاريع المرشحة الأخرى غير الوحدتين المذكورتين.

التحقق المنفذ دون بناء
---------------------
- اجتاز git diff --check في مراجعة المصدر.
- تم تحليل ملفات XML الخمسة في موارد التطبيق بواسطة محلل XML قياسي.
- فُحص ساكنًا وجود قيود الحجم/العدد وSHA-256، وربط SettingsScreen، وعدم وجود أذونات تخزين واسعة في Manifest.
- فُحص عدم وجود ملفات APK في مجلد المشروع.
هذه الفحوص لا تثبت ترجمة Kotlin أو تشغيل Android؛ يلزم تشغيل Gradle والاختبارات لاحقًا للحصول على ذلك، وهو لم يُنفذ الآن.

الحدود المعتمدة
----------------
- لم أُنشئ APK، ولم أُنزّل موارد أو محتوى إعلامي أو كتبًا، ولم أفعّل مصادر خارجية.
- Zangetsu مستبعد كما طلبت.
- لم أضع أزرارًا أو خيارات لمشغلات/مصادر غير موجودة على أنها ميزات مكتملة.
- وضع المشروع الحالي هو مصدر Android قابل للمراجعة مع ميزات محلية مدمجة في الشيفرة، وليس نسخة نهائية مثبتة أو مختبرة.

طريقة المتابعة بعد موافقتك على حل الاعتماديات والبناء
----------------------------------------------------
1. تشغيل اختبارات الوحدتين المصدرّيتين.
2. ترجمة التطبيق دون نشره، ثم معالجة أخطاء التوافق الفعلية.
3. اختبار EPUB/CBZ/الفيديو وSAF والنسخ الاحتياطي على جهاز/محاكي.
4. اختيار مستودعات/أنظمة الإضافات المقصودة والتحقق من ترخيص كل وحدة وتبعياتها قبل دمجها.
5. تنفيذ مراحل التنزيل/التتبع/المفضلات/الذكاء الاصطناعي فقط بعد تثبيت المصادر والواجهات ومزودي الخدمة المطلوبين.
